# Ram Motors Website

A static, Bootstrap-based website for Ram Motors, built to be easy to host on GitHub Pages.

## Files

- `index.html` — main page content
- `styles.css` — custom styling
- `script.js` — small enhancement for footer year

## Preview locally

Open `index.html` directly in a browser, or run:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deploy to GitHub Pages

1. Push this folder to your GitHub repository.
2. In the repository settings, enable GitHub Pages.
3. Choose the root folder or the main branch as the source.
4. Your website will be available at your GitHub Pages URL.
